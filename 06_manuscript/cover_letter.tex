\opening{Dear Editor,}

We submit for consideration as an \textit{Application Note} our manuscript entitled:

\medskip
\textbf{Agentic skill files measurably improve virtual screening quality: a benchmarking study with Claude Code on FPR2}

\medskip
This paper describes a controlled benchmark study comparing two virtual screening (VS) protocols generated by Claude Code (Claude Opus 4.6, Anthropic), an AI coding agent: (1) a \textit{naive} pipeline using OpenBabel defaults, and (2) a \textit{skill-guided} pipeline informed by a structured domain-knowledge skill file encoding expert VS conventions. Both protocols were applied to the G protein-coupled receptor FPR2 (CHEMBL4227, PDB 7T6S) using 100 curated actives and $\sim$4,780 property-matched decoys docked with GPU-accelerated Uni-Dock.

The work is directly relevant to the \textit{Bioinformatics} readership for the following reasons:

\begin{enumerate}

  \item \textbf{Timely problem}: LLM-based coding agents are now widely used to write computational pipelines, but their lack of domain expertise is a recognised limitation. We present the first quantitative benchmark demonstrating that structured skill files—a lightweight knowledge-injection mechanism—measurably improve VS enrichment performance.

  \item \textbf{Reproducible framework}: All data, code, and the skill file itself are provided. The benchmark infrastructure is reusable for other receptor targets and docking engines.

  \item \textbf{Rigorous statistical analysis}: We apply DeLong's non-parametric AUC comparison test, bootstrap permutation tests for BEDROC and enrichment factor differences, Mann-Whitney $U$ tests for score distributions, Net Reclassification Improvement at EF$_{1\%}$, and Benjamini-Hochberg FDR correction throughout.

  \item \textbf{Conciseness}: The manuscript is structured as an Application Note ($\leq$1,300 words body text) with one main figure and supplementary material.

\end{enumerate}

This manuscript has not been published elsewhere and is not under consideration at another journal.
